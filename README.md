## 👨‍🎓 Étudiants
- Floryan Bornet  
- Corentin Brendlé

## 🎯 Objectif pédagogique
Ce projet a pour but d’explorer différentes **stratégies d’authentification** (Session, JWT, OAuth2) et de développer une **interface de messagerie instantanée** avec gestion des sessions et cache. Le tout est réparti en **trois mini-projets** distincts, chacun hébergé dans son propre dépôt GitHub.

---

## 📁 Organisation du dépôt principal

Ce dépôt principal centralise les **liens vers les trois mini-projets** :

| Mini-projet | Description | Lien GitHub |
|-------------|-------------|-------------|
| 1️⃣ Authentification avec Passport-Local & Session | Authentification via cookies et sessions | [🔗 Voir le dépôt](https://github.com/BornetFloryan/Authentification-avec-Passport-Local-et-Session) |
| 2️⃣ Authentification avec JWT | Authentification via JSON Web Token et stockage côté client | [🔗 Voir le dépôt](https://github.com/BornetFloryan/Authentification-avec-JWT-JSON-Web-Token-) |
| 3️⃣ Authentification OAuth2 + Chat en temps réel | Connexion Google + Chat avec Socket.io et cache Redis | [🔗 Voir le dépôt](https://github.com/BornetFloryan/Authentification-OAuth2-avec-Google-et-Chat-en-temps-reel.git) |

---

## ▶️ Lancement rapide

Chaque mini-projet est indépendant. Se référer aux **README individuels** dans chaque dépôt pour les instructions spécifiques. Voici un aperçu général :

```bash
# Cloner le dépôt souhaité
git clone https://github.com/BornetFloryan/services-web-PROJET

# Accéder au backend
cd backend
npm install
npm run dev

# Accéder au frontend
cd frontend
npm install
npm run dev
```
